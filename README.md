# Wazuh SIEM Detection Engineering Environment

Custom Wazuh SIEM detection rules mapping Active Directory threat events to the MITRE ATT&CK framework (T1078 - Valid Accounts).

> **Portfolio note:** This is a focused standalone companion repository. The authoritative recruiter-facing portfolio and broader Wazuh evidence are maintained in [hnmasiya/cybersecurity-portfolio](https://github.com/hnmasiya/cybersecurity-portfolio), particularly under `SIEM/Wazuh/` and `SOC/Flagship-Investigation/`.

## Scope

This repository is intentionally lightweight and focused on the original Wazuh detection-engineering concept. The main portfolio contains the expanded evidence, live endpoint integration, investigation work and newer detection-validation artifacts.
