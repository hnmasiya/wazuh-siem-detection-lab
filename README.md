# Wazuh SIEM Detection Engineering Environment

**SOC / SIEM / Detection Engineering**

Custom Wazuh SIEM detection rules for Active Directory threat events, with MITRE ATT&CK mapping and log-analysis workflows.

### Recruiter Quick View

- **Focus:** SOC operations, SIEM, detection engineering and Windows/Active Directory monitoring
- **Platform:** Wazuh
- **Framework:** MITRE ATT&CK — T1078 Valid Accounts
- **Workflow:** Windows/AD telemetry → detection rule → alert → analyst investigation
- **Evidence boundary:** Standalone companion lab; broader evidence is maintained in the main cybersecurity portfolio
